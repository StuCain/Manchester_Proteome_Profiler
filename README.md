# Description
Manchester Proteome Profiler is an app for generating heatmaps, clustering and GO analysis of clusters using the output files from MaxQuant, FragPipe or Proteome Discoverer. BFDR cutoff values can set at the beginning of the script to generate an appropriate length protein list. Alternatively if SAINTexpress analysis is not applicable the protein list can be generated from Significant Protein List generated by LFQ_Analyst.

You can load either the proteinGroups.txt output from MaxQuant, the Abundance data from Proteome Discovery, or the combined_protein.tsv (LFQ) or protein group matrix.tsv (DIA) from FragPipe.
### Load Data
Use the browse button to upload data file, the input box will change depending on the Data File type selected.
### Load Experimental Design template
The Experimental template matches the column titles from your data file to the sample conditions of your data. It consists of five columns (label, condition, replicate, condition_type and bait_id). The **label column** must match the column titles, the **condition column** can be any (short) description, **it should not start with a number, e.g. use "drug_4h" not "4h_drug" **(use only _ or . special characters). The **replicate column** just contains a replicate number (see example below). The last two columns are needed for SAINTexpress analysis. SAINTexpress processing allows identification of proteins that were enriched compared with the control samples. The **bait_id column** must contain either "T" for tested samples or "C" for control samples. If are different experimental conditions which have different matching controls, the matching samples for each of the conditions should be labelled in the **condition_type column**. The condition_type can be labelled with any label, e.g. "1", "2" and "3" of "24hr", "48hr" or "72hr". **If SAINTexpress analysis is not needed these columns can be left unaltered**
### Generate Experimental template
To simplify the process a template for the experimental design file can be generated using the "Save Exp. Template" button. Upload the data file first, this will then allow the label column to be automatically filled in from the column titles of the intensity columns. The replicate column is also filled in with the last character, (usually the replicate number). The **condition_type** and **bait_id** are also filled in, however the "T" will needed to changed to a "C" for the control samples for SAINTexpress analysis to be performed. If SAINTexpress analysis is not needed, these columns may be left as they are. Use a spreadsheet editor to modify the Exp. Template, make sure you you save it in the same format (tab-separated txt. file).


### Choose Comparisons
The app can process either one set of comparisons, two sets of comparisons or one set of comparisons with SAINTexpress processing. 
The comparisons choices are generated automatically from the condition column of the Experimental Design file and are in both orientations. Eg. Cond.A_vs_Cond.B and Cond.B_vs_Cond.A. Multiple comparisons can be selected from the drop down box.
### Second round of comparisons
If the "2 Rounds of comparisons" is selected a further drop box will appear. This allows two independent comparisons with different cut-off values, to be analysed, which are then  combined to generate a protein list that common to both. The 2nd round comparisons are chosen in the same manner as the 1st. 
### Comparisons File input
If there are a large amount of conditions it is advised to generate a comparison file. This can be generated by downloading the Comp. template. This contains a list of the conditions the are generated from the Exp template, in the 1st column, which can then be copied into the 2nd and 3rd columns for the 1st round of comparisons, or the 4th and 5th columns for the 2nd round comparisons. If SAINTexpress analysis is performed only the 1st round of comparisons will be used. See the image below for guidance.


### Two dataset comparison mode
If the Two Dataset comparison mode toggle is activated, this now allows two separate data files to be loaded. They can be from the same data-type or different (eg. MaxQuant and FragPipe analysis, or FragPipe DDA and DIA data). Each must have is own Experimental Design file, which can be generated from its specific template file. The comparison template file will now have a sixth column containing the list of the conditions from the second Experimental Template, which must be used to generate the conditions for the second round of comparisons (4th and 5th columns). 


### Start Analysis
After the comparisons have been selected press the "Analyse" button to begin the calculations.

### Abundance Heatmap
This shows a heatmap of the log2 Intensity values of the most abundant proteins as ranked by their average log2 intensity over all the samples. The number of most abundant proteins can be changed using the input box, and the values can be switched from _imputed_ to _normalised_ values. Normalised values will contain missing values indicated by grey boxes. The heatmap can also be switched to show just the proteins from the significant protein list. The top annotation shows a violin plot indicating the log2 intensity values for each sample, for the proteins shown. The right annotation shown the mean intensity value for each protein, if normalised values are chosen the missing values are excluded from mean calculation.  The plot can be downloaded using the "Save heatmap" button. It can be can be resized using the "PDF Width" and "PDF Height" buttons. Below the the heatmap is a table containing the heatmap values along with information on the protein name and accession ID. This can be downloaded using the "Save Abundance Table" button. If a second dataset is loaded a second Abundance Heatmap will be available.

This contains points for all the filtered proteins, with the significant proteins indicated. Text size can be changed, or removed. All volcano plots can be saved as pdf files and resized using the "PDF Width" and "PDF Height" buttons.

### Correlation Plots


### PCA
The Principle Component Analysis plot shows similarities between groups of samples in a data set. Each point on a PCA plot represents a correlation between an initial variable and the first and second principal components. Ideally the points should be grouped together for each of the conditions (as shown), rather than grouped by replicate, or grouped randomly. The plot can be saved as a pdf file and resized using the "PDF Width" and "PDF Height" buttons. The values used to generate the plot can also be downloaded for plotting in another application using the "Save Values" button. If two datasets are loaded a second PCA plot will be available. 


### Correlation
The correlation tab shows heatmap showing the Pearson correlations between the different samples, using ratio data from the chosen comparisons. Ideally the sample replicates should be grouped together for each condition. If the plot is uniformly coloured over the entire plot this indicated there is only small differences between the samples. If two rounds of comparisons are chosen a second correlation plot is shown in a separate tab, based on the ratios from the second set of comparisons. The plots can be saved as a pdf files and resized using the "PDF Width" and "PDF Height" buttons. If two datasets are loaded a second Correlation plot will be available.


### Frequency Plot
The frequency tab shows a histogram showing proteins that are differentially enriched/expressed in multiple comparisons. It indicates the distribution of significant conditions per protein and the overlap between conditions. If two rounds of comparisons are shown a second frequency plot is shown in a separate tab, based on the significant proteins from the second set of comparisons. The plots can be saved as a pdf files and resized using the "PDF Width" and "PDF Height" buttons.


### QC Plots


### Protein Numbers
This plot shows the number of identified proteins per sample after filtering. Filtering can be controlled using the "Missing value threshold as described earlier. 


### Normalisation
The data is background corrected and normalised by variance stabilizing transformation (vsn). The distribution of the protein intensities is indicated for each sample before and after normalisation. The normalisation method can be switched to quantile normalisation using the radio button on the "Normalisation options" drop down menu on he sidebar.




### Imputation
The imputation plot shows the effect on the protein intensities of imputation of missing values. The default method ("Man") is a  manually defined left-shifted Gaussian distribution (MNAR). The results in a peak  appearing on the left side of the intensity distribution on the lower plot. This peak can be adjusted to be closer or further away from the main distribution using the "Left-shifted Gaussian distribution" input box on the "Imputation options" section of the sidebar. Other imputation options can also be selected there. Usually the default settings are sufficient, if different imputation setting are needed, more detailed information on the other imputation options can be found by clicking on the "Detailed information link".



### Sample Coverage, Missing values-Quant and Missing Values - Heatmap plots
For a detailed description of the other QC plots, a detailed explanation can be found at the ["Introduction to DEP"](https://bioconductor.riken.jp/packages/3.8/bioc/vignettes/DEP/inst/doc/DEP.html) web pages. 


## Cluster Analysis Tab  


### Complex Heatmap
The Complex Heatmap is generated from either the Significant Proteins from the 1st Round of comparisons (COMP1), or either the overlapping proteins from the 1st and 2nd rounds of comparisons (2 Rounds of Comparisons) or the overlapping proteins from the SAINTexpress analysis and the 1st round of comparisons. The title pain above the heatmap will indicate which option has been chosen, along with the fold change and p.adj/p.val cut-off values chosen. If SAINTexpress analysis is used the BFDR Cut-off and BFDR Freq values are indicated. 
**Top Annotation** Violin plots indicate the range and distribution of the log2FC values for each of the comparisons. The FC_means shows the colour and intensity of the mean of the log2FC values for each comparison. 
**Right Annotation** Gene names are indicated on the right hand side along with  histograms indicating the number of times that protein has passed the significance cut-off values (FC and p.adj/p.val) This will range from 1 up to the number of pairwise comparisons chosen. If 2 rounds of comparisons are chosen there will be a histogram for each set of comparisons. If SAINTexpress analysis is chosen the histograms will indicate the pairwise comparison frequency and the number of times the protein has passed the SAINTexpress cut-off values (BFDR and BFDR_Freq). 
**Left Annotation** The colour of the Cluster boxes can be changed with the "Choose palette" selector box. The colour of the cluster boxes is replicated in the Enhanced Volcano Plots.
**Kmeans cluster** The number of Kmeans clustered can be altered using the input box above, up to a maximum of 6 clusters. The number of clusters needed is best assessed by observing the block patterns generated by the data. You can also choose whether to perform hierarchical clustering on the comparisons using the "Cluster columns" toggle. If a specific ordering of the comparisons is wanted, this can be controlled by the order of the comparisons in the comparisons file.
**Heatmap customisation** The high and low colours can be changed using the "High Colour" and "Low Colour" input boxes. The intensity of the log2FC values in the heatmap can be altered using the "Colour Limit (log2)" input box. This can be using if the heatmap is either under or over saturated. Finally a range of palettes is available, which will give different colours. The intensities of the colours can be reduced using the "Alpha" input box. (Values between 0 and 10).
The complex heatmap can be saved as a pdf file and resized using the adjacent "PDF Width" and "PDF Height" buttons.


### Cluster Heatmap
Each individual cluster can be rendered as a heatmap by selecting the "Cluster" tab on the right hand side. The cluster heatmap to be displayed can be selected using the "Cluster No." input box. The resulting heatmap is rendered with a top annotation using fold change data from the protein displayed in that cluster only. The colour scheme of the heatmap will match the initial complex heatmap.  
The cluster heatmap can be saved as a pdf file and resized using the adjacent "PDF Width" and "PDF Height" buttons. 
**Cluster table** The Gene symbol name, protein name and Uniprot ID for each of the protein in the chaosen cluster is displayed at the right hand side of the cluster heatmap. This can be downloaded using the "Save Cluster Table" button.  
A table containing all the significant proteins and the specific cluster they are found can be downloaded using the "Save All Clusters" button. 


### Enhanced Volcano
Enhanced volcano plots can be generated for all the comparisons chosen. These plots show the positions on the volcano plot for the significant protein list only. The colour of the points is dependent on the cluster group it belongs to. The colour scheme will also match the palette chosen in the complex heatmap.
The enhanced volcano plot can be saved as a pdf file and resized using the adjacent "PDF Width" and "PDF Height" buttons.


### Box plots
Box plots showing the log2 intensity values for each condition for all the proteins from chosen cluster are shown. The intensity values can be switched between imputed values or normalised only values, and the chosen cluster number can be changed. These plots can be used to asses the effect of imputation on the data and to identify which values were missing. It can also be used to evaluate the quality of each the replicates to observe if any set of replicates were consistent outliers.
The box plots can be saved as a pdf file and resized using the adjacent "PDF Width" and "PDF Height" buttons.


### Gene Ontology plots
The Gene Ontology plots are generated from the proteins listed in each cluster of the complex Heatmap, and uses the clusterProfiler package. Each cluster is used to calculate enriched functional profiles using enrichGO, which are then aggregated to generate a single plot. All three GO domains can be tested, "Molecular Function", "Cellular Component" and "Biological Process" and the enrichment results are displayed as a "Dot plot" and a "Network plot". The "GO level" input box can be used to show either more global GO terms (lower number) or more granular GO terms (higher number).
Both plots can be saved as a pdf file and resized using the adjacent "PDF Width" and "PDF Height" buttons and a table of Go enrichment result data can be downloaded.
